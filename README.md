# Matrix Calculator

## Sobre o projeto

A Matrix Calculator é uma calculadora desenvolvida em Python, com uma interface gráfica inspirada no universo Matrix.

O projeto faz parte dos meus estudos práticos de Engenharia de IA, com foco no desenvolvimento de software, na organização do código e no uso de ferramentas de desenvolvimento.

## Tecnologias planejadas

- Python
- CustomTkinter
- Git e GitHub para versionamento e registro do desenvolvimento

## Funcionalidades planejadas

- Operações aritméticas básicas: adição, subtração, multiplicação e divisão.
- Uso de parênteses em expressões matemáticas.
- Interface gráfica com tema Matrix.
- Tabelas de multiplicação de 2 a 9 como funcionalidade secundária. (Ainda está em anaise)
- Uso de `○` ao envés de `=`
